# GET /api/v1/subscriptions/{external_ref}

Current subscription status for one user of your app. Requires auth ([HMAC or Firebase ID Token](02-authentication.html)).

With Firebase ID Token, `external_ref` in the URL **must** match the token's own `sub` claim — requesting another user's `external_ref` returns `403 forbidden`. With HMAC, you can query any `external_ref` that belongs to your app (your backend is trusted to enforce its own authorization before calling this).

## Response — success

```json
{ "success": true, "data": { "plan_ref": "premium_1m", "status": "active", "current_period_end": "2026-04-15 00:00:00" } }
```

`status` is one of `active` / `canceled` / `expired`.

## Response — no subscription yet

```json
{ "success": false, "error": { "code": "not_found", "message": "No subscription found for this external_ref." } }
```

HTTP 404. Not necessarily an error condition in your own flow — a user who has never checked out simply has no subscription record.
