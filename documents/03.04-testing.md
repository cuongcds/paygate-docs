# Testing without a real Stripe account

Send `payment_method="test"` with one of these `test_card_code` values on [checkout-sessions](03.01-checkout-sessions.md) (only allowed when your app's environment is `test` or `staging`):

| `test_card_code` | Outcome |
| --- | --- |
| `4242424242424242` | `success` |
| `4000000000000002` | `invalid_card_details` (400) |
| `4000000000009995` | `insufficient_funds` (402) |

These numbers match Stripe's own published test cards purely so they're easy to recognize — PayGate never actually calls Stripe for this `payment_method`, the outcome is resolved synchronously and locally.
