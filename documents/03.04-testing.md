# Testing without a real Stripe account

`POST /api/v1/checkout-sessions` never accepts `payment_method="test"` or a `test_card_code` — that endpoint only ever creates a `pending` transaction and returns a `checkout_url`, never a card/payment result.

To test without a real Stripe account: call `checkout-sessions` **without** `payment_method` on an app whose environment allows the Test Payment Method (`test` or `staging`). You get back a `checkout_url` pointing to PayGate's hosted picker page ([GET /checkout/{public_token}](03.03-checkout-page.html)). On that page, choose **Test Payment Method** and submit one of these card codes:

| `test_card_code` | Outcome |
| --- | --- |
| `4242424242424242` | `success` |
| `4000000000000002` | `invalid_card_details` (400) |
| `4000000000009995` | `insufficient_funds` (402) |

These numbers match Stripe's own published test cards purely so they're easy to recognize — PayGate never actually calls Stripe for this payment method, the outcome is resolved synchronously and locally, entirely within the picker page's own resolve step — never inside `checkout-sessions` itself.
